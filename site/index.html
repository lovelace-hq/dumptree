How the parser thinks

Plain var_dump output, with multiple dumps supported. String lengths count UTF-8 bytes, including quotes and line breaks. HTML and Xdebug formatting aren't supported.

JSON exports values, not PHP classes or visibility. Recursion, enums, resources, uninitialized values, non-finite floats and integers outside JavaScript's safe range become strings. Empty PHP arrays become []. Flat view retains paths and types.

Limit 1 million characters, 20,000 values, 100 levels. Search affects tree and table only. Hide protected/private also affects JSON exports.

Your input is parsed locally, never executed. Share links contain the full dump, including hidden properties. Don't share secrets.
